## 程式用途與 Colab 執行方式
### 程式用途
使用 Python 的 `tuple`、`list`、`set`、`dict` 與字串方法整理「桌遊體驗」與「電影欣賞」兩場活動報名名單，去除重複報名並比較交集、聯集與差集，最後計算各場應收與總應收費用並輸出摘要。

### 如何在 Google Colab 開啟並執行
1. 開啟 Google Colab 並上傳本專案的 `.ipynb` 筆記本檔案。
2. 依序執行「測試一」「測試二」「測試三」三個程式碼儲存格（`Shift + Enter`）。
3. 核對各組輸出的人數、名單與總應收金額。

## 三組測試結果摘要
- **測試一（原始資料）**：桌遊 3 人、電影 3 人、共同 1 人（`['ben']`）、總不重複 5 人、報名 6 人次、總應收 `600.00` 元。
- **測試二（新增電影參加者 Frank）**：桌遊 3 人、電影 4 人、共同 1 人（`['ben']`）、總不重複 6 人、報名 7 人次、總應收 `680.00` 元。
- **測試三（兩場去重後完全相同）**：桌遊 3 人、電影 3 人、共同 3 人（`['amy', 'ben', 'cora']`）、只參加桌遊 `[]`、只參加電影 `[]`、總不重複 3 人、報名 6 人次、總應收 `600.00` 元。
